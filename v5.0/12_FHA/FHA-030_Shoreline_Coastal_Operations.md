## 1. Scope

This FHA covers RPAS operations conducted on shorelines, beaches, coastal cliffs, tidal zones, jetties, seawalls, and other coastal environments. Operations include coastal erosion monitoring, marine wildlife surveys, search and rescue support, infrastructure inspection, environmental assessment, and recreational beach monitoring. Hazards unique to the coastal environment including tides, waves, salt exposure, and marine wildlife are addressed.

## 2. Risk Matrix

**Likelihood:**
| Rating | Description |
|:-------|:------------|
| 5 | Almost Certain |
| 4 | Likely |
| 3 | Possible |
| 2 | Unlikely |
| 1 | Rare |

**Severity:**
| Rating | Description |
|:-------|:------------|
| 5 | Catastrophic (fatality, permanent disability) |
| 4 | Major (serious injury, significant damage) |
| 3 | Moderate (medical treatment, moderate damage) |
| 2 | Minor (first aid, minor damage) |
| 1 | Negligible (no injury, minimal damage) |

**Risk Score = Likelihood × Severity**
| Risk Score | Rating | Action |
|:-----------|:-------|:-------|
| 15-25 | HIGH | Stop; implement additional controls |
| 8-14 | MEDIUM | Proceed with controls; monitor |
| 1-7 | LOW | Proceed with awareness |

## 4. Control Summary

### Critical Controls

| Control | Purpose | Responsible |
|:--------|:--------|:------------|
| Tide table review | Prevent tidal entrapment | PIC |
| Safe distance from water | Prevent drowning, equipment loss | PIC |
| Post-flight salt rinse | Prevent corrosion damage | PIC |
| Wind speed limits | Maintain aircraft control | PIC |
| Wildlife distance requirements | Legal compliance, wildlife protection | PIC |
| Emergency communication | Enable rescue response | All personnel |
| Escape route identification | Safe evacuation path | All personnel |

### PPE Requirements

| PPE | When Required |
|:----|:--------------|
| Non-slip footwear | All coastal operations |
| UV-rated sunglasses | Daylight operations |
| Sunscreen (SPF 50+) | All daylight operations |
| High-visibility vest | Near traffic, public areas |
| Hard hat | Cliff/structure proximity |
| Personal flotation device | Within 5m of water edge |
| Waterproof outer layer | Spray/rain conditions |
| Gloves | Equipment handling, sharp debris areas |
