## 1. Purpose

This procedure establishes requirements for conducting Extended Visual Line-of-Sight (EVLOS) operations using Visual Observers to extend the operational range beyond the PIC's direct visual line of sight.

---

## 2. Scope

This procedure applies to:
- All EVLOS operations conducted under Aeria RPOC
- Operations using Visual Observers to extend VLOS
- Pilots and Visual Observers conducting EVLOS
- Operations where RPA transitions between VO coverage areas

---

## 3. Definitions

| Term | Definition |
|:-----|:-----------|
| **EVLOS** | Extended Visual Line-of-Sight - Operations where the PIC uses Visual Observers to maintain continuous visual contact with the RPA |
| **VLOS** | Visual Line-of-Sight - Operations where the PIC maintains direct visual contact |
| **VO** | Visual Observer - Person maintaining visual contact with RPA and communicating with PIC |
| **Handoff** | Transfer of visual tracking responsibility from one VO to another |
| **Coverage Zone** | Geographic area where a VO can maintain effective visual contact |

## 5. EVLOS Overview

### 5.1 What is EVLOS?

EVLOS extends the operational range by positioning Visual Observers along the flight path. At all times during EVLOS operations:
- At least one person (PIC or VO) maintains visual contact with the RPA
- The RPA is never beyond visual contact of all observers
- Communication is maintained between PIC and all VOs

### 5.2 EVLOS vs BVLOS

| Aspect | EVLOS | BVLOS |
|:-------|:------|:------|
| Visual contact | Maintained via VOs | Not maintained |
| Authorization | Advanced Operations | L1C Declaration or SFOC |
| Pilot certificate | Advanced | L1C or SFOC |
| Location restrictions | Per Advanced rules | Per declaration/SFOC |

**EVLOS is NOT BVLOS** - Visual contact is maintained throughout.

---

## 6. Personnel Requirements

### 6.1 PIC Requirements

The PIC for EVLOS operations shall:
- Hold Pilot Certificate - Advanced Operations
- Be authorized on aircraft type
- Complete EVLOS briefing (this procedure)
- Maintain communication with all VOs
- Maintain overall situational awareness

### 6.2 Visual Observer Requirements

VOs for EVLOS operations shall:
- Complete VO training per OPS-008-PR
- Complete additional EVLOS-specific briefing
- Have adequate vision to track RPA at required distances
- Have reliable communication with PIC
- Understand handoff procedures

### 6.3 Minimum Crew

| Operation Type | Minimum Crew |
|:---------------|:-------------|
| PIC maintains visual + VO extends range | PIC + 1 VO |
| PIC loses visual, VO maintains | PIC + 1 VO minimum |
| Multiple VO positions for long range | PIC + 2+ VOs |
| Complex terrain requiring overlapping coverage | PIC + VOs as required |

## 7. Planning EVLOS Operations

### 7.1 Site Assessment

Before EVLOS operations, assess:

| Factor | Assessment |
|:-------|:-----------|
| **Total range required** | Determine distance from GCS to furthest point |
| **Terrain** | Hills, valleys, obstacles affecting VO sightlines |
| **VO positions** | Where VOs can be positioned effectively |
| **Coverage zones** | Area each VO can effectively cover |
| **Overlap areas** | Where handoffs will occur |
| **Communication** | Verify radio/communication coverage |
| **Access** | How VOs reach and depart positions |

### 7.2 VO Positioning

Position VOs to ensure:
- Continuous visual coverage of entire flight path
- Overlapping coverage zones for safe handoffs
- Clear sightlines without obstructions
- Safe, stable position for extended observation
- Communication range maintained

**Maximum VO Coverage Distance:** Typically 500-1000m depending on:
- RPA size and color
- Weather/visibility conditions
- Background (sky vs terrain)
- VO experience and vision

### 7.3 Communication Plan

Establish communication plan including:
- Primary communication method (radio recommended)
- Backup communication method
- Standard calls and responses
- Emergency communication protocol
- Check-in schedule during flight

### 7.4 Coverage Map

For complex EVLOS operations, create coverage map showing:
- PIC/GCS location
- VO positions
- Coverage zones (circles/ellipses)
- Overlap zones for handoffs
- Flight path
- Landmarks for position reference

## 8. EVLOS Procedures

### 8.1 Pre-Flight Briefing

Brief all crew on:

| Topic | Content |
|:------|:--------|
| **Mission overview** | Flight path, objectives, duration |
| **VO positions** | Exact locations for each VO |
| **Coverage zones** | What area each VO covers |
| **Handoff points** | Where handoffs will occur |
| **Communication plan** | Frequencies, calls, check-ins |
| **Emergency procedures** | What to do if visual lost, emergency |
| **Abort criteria** | When to terminate operation |

### 8.2 Communication Protocol

#### Standard Calls

| Call | Meaning | Who |
|:-----|:--------|:----|
| "VO1, radio check" | Communication test | PIC |
| "VO1, loud and clear" | Communication confirmed | VO1 |
| "VO1, visual" | VO1 has visual contact | VO1 |
| "VO2, visual" | VO2 has visual contact | VO2 |
| "VO1, entering overlap" | RPA approaching handoff zone | VO1 |
| "VO2, I have visual" | VO2 confirms visual for handoff | VO2 |
| "VO1, handoff complete" | VO1 releases tracking responsibility | VO1 |
| "Visual lost" | Cannot see RPA | Any VO |
| "Land now" | Emergency landing required | Any |

#### Communication Timing

- Radio check before launch
- Confirm visual after launch
- Position update every 30 seconds or at waypoints
- Immediate call for any concern
- Confirm handoffs verbally

### 8.3 Handoff Procedure

When RPA transitions between VO coverage zones:

```
┌─────────────────────────────────────────────────────────────┐
│                    Handoff Procedure                         │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. Outgoing VO: "RPA entering overlap zone"                 │
│                                                              │
│  2. Incoming VO: Acquires visual, confirms                   │
│     "I have visual"                                          │
│                                                              │
│  3. PIC: Confirms both VOs have visual                       │
│     "Confirm dual visual"                                    │
│                                                              │
│  4. Outgoing VO: Maintains visual until clear of zone        │
│                                                              │
│  5. Outgoing VO: "Handoff complete, releasing"               │
│                                                              │
│  6. Incoming VO: Now primary tracker                         │
│     "VO[X] has the aircraft"                                 │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**Critical Rule:** NEVER release visual contact until incoming VO confirms visual acquisition.

### 8.4 Lost Visual Procedure

If any VO loses visual contact:

1. **Immediately call:** "Lost visual, [last known position/direction]"
2. **PIC:** Stop lateral movement, initiate hover/orbit
3. **Other VOs:** Attempt to acquire visual
4. **If visual regained:** Continue operations
5. **If visual not regained within 30 seconds:**
   - Initiate return to last known visual position
   - If still no visual, initiate RTH or controlled landing
6. **Document occurrence**

### 8.5 Flight Conduct

During EVLOS flight:

| Responsibility | PIC | VO |
|:---------------|:----|:---|
| Aircraft control | Primary | None |
| Telemetry monitoring | Continuous | N/A |
| Visual tracking | When in range | Primary in zone |
| Hazard scanning | Peripheral | Active |
| Communication | Coordination | Reporting |
| Decision authority | Final | Advisory |

## 9. Limitations

### 9.1 Weather Limitations

EVLOS requires adequate visibility:

| Condition | Requirement |
|:----------|:------------|
| Visibility | Minimum 3 SM (statute miles) |
| Cloud ceiling | Minimum 500 ft above flight altitude |
| Precipitation | Light or none |
| Wind | Within aircraft limits |
| Sun glare | Manageable (reposition VOs if needed) |

### 9.2 Distance Limitations

| Factor | Limitation |
|:-------|:-----------|
| Maximum VO tracking distance | 1000m typical (varies by conditions) |
| Minimum overlap zone | 200m recommended |
| Communication range | Must cover entire operation area |

### 9.3 Operational Limitations

- EVLOS operations only during daylight
- Operations over people require additional assessment
- Controlled airspace requires standard authorization
- All Advanced Operations requirements still apply

## 11. Emergency Procedures

### 11.1 Lost Visual - All Observers

If all observers lose visual:
1. PIC initiates immediate hover/loiter
2. Attempt telemetry-based position identification
3. If position known, return to last visual point
4. If position uncertain, initiate RTH
5. All VOs scan for RPA
6. Document as occurrence

### 11.2 Communication Failure

If communication lost with VO:
1. Do not fly RPA into that VO's zone
2. Attempt alternate communication
3. If visual VO contact possible, use hand signals
4. If no communication restored, RTH
5. Document occurrence

### 11.3 VO Incapacitation

If a VO becomes unable to perform duties:
1. Do not fly into affected coverage zone
2. Adjust flight plan to remain in covered areas
3. Consider terminating operation
4. Provide assistance to VO as needed

## 12. Training Requirements

### 12.1 EVLOS-Specific Training

In addition to standard VO training (OPS-008-PR):

| Topic | Content | Duration |
|:------|:--------|:---------|
| EVLOS procedures | This procedure | 30 min |
| Handoff procedures | Practice handoffs | 30 min |
| Communication protocol | Standard calls | 15 min |
| Practical exercise | Actual EVLOS operation | 1 hour |

### 12.2 Practical Exercise

Before acting as VO in EVLOS operations:
- Participate in supervised EVLOS operation
- Practice handoff procedures
- Demonstrate communication protocol
- Successfully track RPA through coverage zone
