## 1. Purpose

This procedure provides step-by-step operational flows for RPAS operations from mobilization to demobilization. These flows ensure consistency, safety, and compliance across all operations.

---

## 2. Scope

This procedure applies to:
- All RPAS field operations
- All crew members (PIC, VO, Ground Crew)
- All operation types (basic, advanced, special)

---

## 3. Operations Flow Overview

Operations follow this sequence:

```
MOBILIZATION
    ↓
1. Operation Documentation Flow
    ↓
2. Kit Preparation Flow
    ↓
3. Team Briefing Flow
    ↓
4. Site Setup Flow
    ↓
5. RPAS Setup Flow
    ↓
6. Operations Ready Checklist
    ↓
7. Power-Up Flow
    ↓
8. Take-Off Checklist (Call & Response)
    ↓
9. Take-Off Flow
    ↓
10. During Flight Flow
    ↓
11. Pre-Landing Flow
    ↓
12. Landing Flow (Battery Swap OR Post-Flight)
    ↓
13. Pack Up Flow
    ↓
14. Team Debrief Flow
    ↓
15. Data Debrief Flow
    ↓
DEMOBILIZATION
```

## 4. Flow Procedures

### 4.1 Operation Documentation Flow

Before departing for site, confirm all required documentation:

| Step | Action | Responsible |
|:-----|:-------|:------------|
| 1 | Site Survey completed and reviewed | Ops Manager |
| 2 | Ground Risk assessed (FHA/FLHA prepared) | Ops Manager |
| 3 | Air Risk assessed (airspace reviewed) | Ops Manager |
| 4 | Wildlife assessment completed | Ops Manager |
| 5 | First Aid assessment completed | Ops Manager |
| 6 | Emergency contacts identified | Ops Manager |
| 7 | All permits/authorizations confirmed | Ops Manager |
| 8 | Documentation distributed to crew | Ops Manager |

**Proceed only when all documentation is complete.**

---

### 4.2 Kit Preparation Flow

Before leaving for the operation site:

| Step | Action | Check |
|:-----|:-------|:------|
| 1 | **Inventory Check** - Verify all equipment and backups | ☐ |
| 2 | **Pre-Operation Inspection** - Check equipment for damage | ☐ |
| 3 | **Battery Check** - All batteries fully charged | ☐ |
| 4 | **Software Updates** - Flight control and nav software current | ☐ |
| 5 | **SD Cards** - Formatted and ready | ☐ |
| 6 | **Documentation Pack** - Certifications, manuals, planning docs | ☐ |
| 7 | **Emergency Kit** - First aid, fire extinguisher | ☐ |
| 8 | **PPE** - High-viz, eye protection, gloves | ☐ |
| 9 | **Communication Equipment** - Radios charged and tested | ☐ |

**Equipment Status:**
- All items accounted for: ☐ YES ☐ NO
- All items functional: ☐ YES ☐ NO
- If NO to either: Do not proceed until resolved

---

### 4.3 Team Briefing Flow

Conduct with all crew members before departing:

| Step | Topic | Details |
|:-----|:------|:--------|
| 1 | **Overview of Operation** | Objectives, expected outcomes, deliverables |
| 2 | **Site Information** | Location, access, terrain, known hazards |
| 3 | **Role Assignment** | PIC, VO, other crew - confirm understanding |
| 4 | **Safety Protocols** | Emergency procedures, first aid location |
| 5 | **Communication Protocols** | Radio channels, standard calls |
| 6 | **Weather Conditions** | Current and forecast, go/no-go limits |
| 7 | **Airspace** | Classification, restrictions, contacts |
| 8 | **Workload Check** | Everyone comfortable? Need assistance? |
| 9 | **Questions** | Address any concerns |

**Briefing Complete:** ☐ All crew confirm understanding

---

### 4.4 Site Setup Flow

Upon arrival at operation site:

| Step | Action | Check |
|:-----|:-------|:------|
| 1 | **Area Inspection** - Walk the site, identify hazards not in survey | ☐ |
| 2 | **Verify Site Survey** - Confirm conditions match documentation | ☐ |
| 3 | **Update FLHA** - Note any new hazards discovered | ☐ |
| 4 | **Establish Launch/Recovery Area** - Clear, level surface | ☐ |
| 5 | **Establish Perimeter** - Safety boundary around operations | ☐ |
| 6 | **Position Emergency Equipment** - First aid, fire extinguisher accessible | ☐ |
| 7 | **Communication Test** - Confirm all radios working | ☐ |
| 8 | **Wind Assessment** - Measure and confirm within limits | ☐ |
| 9 | **Final Airspace Check** - NOTAMs, active traffic | ☐ |

**Site Status:**
- Site matches survey: ☐ YES ☐ NO (if NO, update documentation)
- All hazards controlled: ☐ YES ☐ NO (if NO, do not proceed)

---

### 4.5 RPAS Setup Flow

Preparing the aircraft for flight:

| Step | Action | Check |
|:-----|:-------|:------|
| 1 | **Unpack RPAS** - Handle carefully, place on clean surface | ☐ |
| 2 | **Visual Inspection** - Frame, arms, motors for damage | ☐ |
| 3 | **Propeller Check** - Secure, no nicks or cracks | ☐ |
| 4 | **Payload Installation** - Camera/sensor secured, lens clean | ☐ |
| 5 | **Battery Inspection** - No swelling, damage, or corrosion | ☐ |
| 6 | **Battery Installation** - Seated properly, locked | ☐ |
| 7 | **SD Card Installation** - Confirmed in place | ☐ |
| 8 | **Ground Control Setup** - Tablet/controller powered and connected | ☐ |
| 9 | **AirData Sync** - Confirm pilot credentials synced | ☐ |
| 10 | **Calibration** - Compass if required by system | ☐ |

**RPAS Status:**
- Pre-flight inspection complete: ☐ YES ☐ NO
- All systems functional: ☐ YES ☐ NO

Final confirmation before powering up:

| Item | Status |
|:-----|:-------|
| All team members present and briefed | ☐ |
| All communication systems functional | ☐ |
| RPAS and equipment in place and ready | ☐ |
| Emergency equipment accessible | ☐ |
| Weather within limits | ☐ |
| Airspace clear/authorized | ☐ |
| Site secure | ☐ |

**Operations Ready:** ☐ YES - Proceed to Power-Up

### 4.7 Power-Up Flow

| Step | Action | Announcement |
|:-----|:-------|:-------------|
| 1 | Power up Ground Control Station first | "Ground control on" |
| 2 | Confirm GCS connection ready | — |
| 3 | Power up RPAS | **"RPAS ON"** (loudly) |
| 4 | Wait for system initialization | — |
| 5 | Confirm GPS lock | "GPS locked, [X] satellites" |
| 6 | Confirm home point set | "Home point set" |
| 7 | Confirm failsafe settings | "Failsafe [RTH/Land], [altitude]" |
| 8 | Test gimbal movement | "Gimbal responding" |
| 9 | Test control inputs (without props spinning) | "Controls responsive" |
| 10 | Confirm telemetry showing on GCS | "Telemetry good" |

**System Status:** ☐ All systems nominal - Ready for Take-Off Checklist

---

### 4.8 Take-Off Checklist (Call & Response)

**VO reads the call, PIC responds. A copy should be in every operations kit.**

| VO Call | PIC Response |
|:--------|:-------------|
| "Wind & weather" | Describe conditions. If acceptable: **"Within limits"** |
| "Air vehicle batteries" | Read percentage: **"[X]%"** |
| "Ground control batteries" | Read percentage: **"[X]%"** (include tablet if connected) |
| "Ground control app" | App name, connection status, errors, satellite count |
| "Payload" | List payloads, confirm connected and unobstructed |
| "Failsafe" | Mode (RTH/Land), RTH altitude, battery failsafe level |
| "Take-off mode" | **"P-GPS"** (or applicable mode) |
| "Area & air traffic" | Note aircraft, traffic, obstacles, interference sources |
| "Cleared for takeoff" | **"CLEAR!"** (loudly) |

⚠️ **DO NOT TAKE OFF** if any response does not meet requirements.

---

### 4.9 Take-Off Flow

| Step | Action |
|:-----|:-------|
| 1 | Confirm area clear of personnel |
| 2 | Arm aircraft |
| 3 | Apply gentle throttle to lift off |
| 4 | Ascend to 3-5 meters, hold hover |
| 5 | Verify stable hover |
| 6 | Test attitude controls (gentle pitch/roll/yaw) |
| 7 | Listen for abnormal sounds |
| 8 | Check telemetry readings normal |
| 9 | If any anomaly: **Land immediately** |
| 10 | If all normal: **"Proceeding with operation"** |

---

### 4.10 During Flight Flow

| Continuous Actions |
|:-------------------|
| Monitor flight path and telemetry |
| Monitor battery level |
| Maintain crew communication |
| Scan for other aircraft (VO primary) |
| Adjust parameters based on real-time conditions |
| Execute mission profile |

**PIC Primary Duty:** Safe operation of the RPAS. Payload operation is secondary.

**VO Duties:**
- Maintain visual contact with RPAS
- Scan airspace for traffic
- Monitor wind and weather changes
- Request periodic read-outs: "Battery?" "Distance?"

---

### 4.11 Pre-Landing Flow

| Step | Action |
|:-----|:-------|
| 1 | Confirm landing area clear and secure |
| 2 | Verify battery sufficient for landing |
| 3 | Check for wind changes affecting approach |
| 4 | Announce: **"Returning"** or **"Landing"** |
| 5 | Begin controlled approach to landing area |

---

### 4.12 Landing Flow

#### Option A: Landing with Battery Swap (continuing operations)

| Step | Action | Announcement |
|:-----|:-------|:-------------|
| 1 | Position over landing area | "Approach" |
| 2 | Execute controlled descent | "Landing initiated" |
| 3 | Touch down gently | — |
| 4 | Disarm aircraft | — |
| 5 | Allow system to power down | "RPAS safe for approach" |
| 6 | VO approaches, swaps battery | — |
| 7 | VO inspects RPAS (rotors, body) | — |
| 8 | VO confirms battery installed, backs away | "Ready for pre-flight" |
| 9 | PIC requests Take-Off Checklist | — |
| 10 | Complete checklist, announce | "CLEAR!" |

#### Option B: Landing - Post-Flight (ending operations)

| Step | Action | Announcement |
|:-----|:-------|:-------------|
| 1 | Position over landing area | "Approach" |
| 2 | Execute controlled descent | "Landing initiated" |
| 3 | Touch down gently | — |
| 4 | Disarm aircraft | — |
| 5 | Power down RPAS | "RPAS off" |
| 6 | Power down Ground Control | "Ground control off" |
| 7 | VO approaches | "RPAS safe for approach" |
| 8 | Remove battery | — |
| 9 | Conduct post-flight inspection | — |

### 4.13 Pack Up Flow

| Step | Action | Check |
|:-----|:-------|:------|
| 1 | Disassemble RPAS carefully | ☐ |
| 2 | Remove and store batteries (LiPo safe bag) | ☐ |
| 3 | Clean payload lens/sensors | ☐ |
| 4 | Secure all components in case | ☐ |
| 5 | Collect all equipment and gear | ☐ |
| 6 | **Inventory Check** - All items accounted for | ☐ |
| 7 | Clear site of any debris or equipment | ☐ |
| 8 | Leave site as found or better | ☐ |

### 4.14 Team Debrief Flow

Conduct before leaving site:

| Topic | Discussion |
|:------|:-----------|
| **Objectives Met?** | Were operation goals achieved? |
| **Issues Encountered** | Any problems? How were they handled? |
| **Situational Awareness** | Any challenges? How to avoid? |
| **Procedures** | Did procedures work? Any improvements? |
| **Safety Observations** | Any safety concerns or near-misses? |
| **Equipment Performance** | Any issues to log for maintenance? |
| **Feedback** | Input from each team member |

**Action Items:** Document any follow-up actions needed.

---

### 4.15 Data Debrief Flow

After returning from site:

| Step | Action |
|:-----|:-------|
| 1 | **Download Data** - Transfer all flight data to workstation |
| 2 | **Backup Data** - Copy to secure backup location |
| 3 | **Review Flight Logs** - Check for anomalies or warnings |
| 4 | **AirData Upload** - Ensure flights synced to AirData |
| 5 | **Assess Performance** - Review against objectives |
| 6 | **Document Findings** - Note successes and issues |
| 7 | **Client Deliverables** - Prepare data for delivery |
| 8 | **Lessons Learned** - Feed back into procedures if needed |

---

### 4.16 Equipment Management Flow

After each operation:

| Step | Action |
|:-----|:-------|
| 1 | **Charge Batteries** - All batteries to storage charge |
| 2 | **Clean Equipment** - Remove dirt, debris |
| 3 | **Inspect for Damage** - Log any issues discovered |
| 4 | **Update Maintenance Log** - Record flight time in AirData |
| 5 | **Schedule Maintenance** - If due based on hours/cycles |
| 6 | **Restock Consumables** - SD cards, props, etc. |
| 7 | **Store Properly** - Temperature-controlled, dry storage |
