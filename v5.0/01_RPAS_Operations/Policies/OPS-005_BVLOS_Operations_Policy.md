## 1. Purpose

This policy establishes requirements for conducting Beyond Visual Line-of-Sight (BVLOS) operations under Aeria Solutions' Level 1 Complex (L1C) Declaration.

- BVLOS flight training operations

## 5. Policy

### 5.1 Authorization Framework

Aeria Solutions conducts BVLOS under L1C Declaration, which permits:
- Operations over unpopulated areas
- Operations in uncontrolled airspace Class G
- Specific aircraft types listed in declaration
- Operators meeting qualification requirements

All BVLOS operations shall comply with:
- L1C Declaration conditions
- Company BVLOS procedures
- Applicable regulatory requirements

### 5.2 BVLOS Categories

| Category | Description | Authorization |
|:---------|:------------|:--------------|
| **Standard L1C** | Within declaration parameters | PIC authority |
| **Non-Standard** | Outside declaration parameters | SFOC required |
| **Training** | Flight instruction | CFI approval |

### 5.3 Operational Limitations

L1C Declaration limitations (verify against current declaration):

| Parameter | Limitation |
|:----------|:-----------|
| **Location** | Unpopulated areas only |
| **Airspace** | Class G uncontrolled |
| **Altitude** | Per declaration (typically 400 ft AGL max) |
| **Range** | Per declaration and C2 link |
| **Aircraft** | Listed aircraft only |
| **Weather** | VMC conditions |

### 5.4 Pilot Requirements

BVLOS PICs shall hold the following **regulatory certifications** (TC-issued):
1. **Pilot Certificate - Advanced Operations** (TC-issued)
2. **Pilot Certificate - Level 1 Complex Operations** (TC-issued per CAR 901.76)

And complete the following **company requirements**:
3. Complete Aeria L1C ground training per Standard 922.67 curriculum (see OPS-004 Section 4.3.1)
4. Complete minimum 5 supervised BVLOS practical training flights
5. Pass BVLOS competency assessment with Operations Manager
6. Hold written BVLOS authorization letter from Operations Manager
7. Maintain BVLOS currency (1 flight per 90 days)

**CRITICAL:** Both TC certificates (Advanced AND L1C) must be valid AND company authorization must be current before conducting any BVLOS operation. Verify both before each L1C operation.

### 5.5 Aircraft Requirements

BVLOS aircraft shall:
1. Be listed on L1C Declaration
2. Have functional C2 (command and control) link
3. Have lost link procedures programmed
4. Have GNSS navigation capability
5. Have telemetry for position monitoring
6. Meet maintenance requirements per MCM
7. Be inspected per BVLOS pre-flight checklist

### 5.6 Site Requirements

BVLOS sites shall:
1. Be surveyed and assessed in advance
2. Be confirmed as unpopulated
3. Have no controlled airspace intrusion
4. Have identified emergency landing zones
5. Have communication coverage confirmed
6. Be documented on site survey form

### 5.7 Pre-Flight Requirements

Before BVLOS flight:
1. Site survey complete
2. NOTAM check complete
3. Weather assessment confirms VMC
4. Aircraft pre-flight complete (BVLOS checklist)
5. C2 link verified
6. Lost link procedures confirmed
7. Emergency procedures reviewed
8. FLHA complete (BVLOS-specific)
9. Flight plan filed (company system)

### 5.8 Flight Conduct

During BVLOS operations:
- Continuous telemetry monitoring required
- C2 link monitoring required
- Position tracking at all times
- Immediate response to anomalies
- Ready to execute lost link procedures
- Communication with any visual observers

### 5.9 Lost Link Procedures

If C2 link lost:
1. Follow aircraft-specific lost link procedures
2. Monitor telemetry for aircraft position
3. Attempt link recovery
4. If link not recovered, aircraft executes automatic procedures
5. Document occurrence
6. Report per SMS requirements

### 5.10 Emergency Procedures

BVLOS emergency procedures address:
- Lost link
- Flyaway
- In-flight emergency
- Forced landing in unpopulated area
- Loss of telemetry
- Unexpected airspace incursion

See OPS-011-PR Emergency Procedures (RPAS)

### 5.11 Post-Flight Requirements

After BVLOS flight:
1. Complete flight log
2. Download and review flight data
3. Document any anomalies
4. Complete post-flight inspection
5. Report occurrences per SMS-005
