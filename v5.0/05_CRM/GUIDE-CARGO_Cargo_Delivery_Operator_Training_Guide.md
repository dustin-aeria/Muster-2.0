## 1. Purpose

This training guide provides the curriculum, learning objectives, and competency requirements for personnel conducting RPAS cargo delivery operations using the DJI FlyCart 30 and FlyCart 100 aircraft.

---

## 2. Scope

This guide applies to:
- Pilots-in-Command (PIC) for cargo operations
- Safety Pilots for Heavy RPAS operations
- Visual Observers supporting cargo delivery
- Ground Crew personnel handling cargo

---

### 3.1 General Prerequisites

## 5. Level 1: Foundation Training

### 5.1 Module 1.1: Regulatory Framework (2 hours)

**Learning Objectives:**
- Understand CARs Part IX RPAS regulations
- Identify SFOC requirements for cargo operations
- Explain Heavy RPAS (>150 kg) regulatory requirements
- Describe Transport Canada engagement requirements

**Topics:**
1. CARs Part IX overview
2. RPAS weight categories
3. SFOC application process
4. Heavy RPAS direct TC engagement
5. Insurance requirements
6. Record keeping requirements
7. Occurrence reporting

**Assessment:** Written quiz (80% pass)

### 5.2 Module 1.2: Cargo Operations Overview (2 hours)

**Learning Objectives:**
- Describe cargo delivery concepts
- Identify aircraft types and capabilities
- Explain delivery methods
- Understand weight and balance principles

**Topics:**
1. Cargo delivery applications
2. FlyCart 30 capabilities
3. FlyCart 100 capabilities
4. Weight and balance fundamentals
5. Cargo securing principles
6. Delivery modes (landing vs. winch)
7. Operational planning basics

**Assessment:** Written quiz (80% pass)

---

## 6. Level 2: FlyCart 30 Qualification

### 6.1 Module 2.1: Aircraft Systems (3 hours)

**Learning Objectives:**
- Describe FlyCart 30 systems and components
- Explain propulsion and battery systems
- Understand avionics and safety features
- Identify cargo bay and winch systems

**Topics:**
1. Aircraft specifications
2. Frame and propulsion
3. Battery configurations (single/dual)
4. Flight controller and navigation
5. Safety systems (parachute, RTH)
6. Cargo bay operation
7. Winch system operation
8. Controller functions

**Assessment:** Systems identification test (90% pass)

### 6.2 Module 2.2: Weight and Balance (2 hours)

**Learning Objectives:**
- Calculate aircraft weight and balance
- Verify CG within limits
- Use weight and balance calculator
- Determine endurance for given payload

**Topics:**
1. Weight components
2. CG calculation
3. Payload limits
4. Battery configuration impact
5. Endurance tables
6. Using FRM-CARGO-WB
7. Go/no-go decisions

**Practical Exercise:** Complete 3 W&B calculations

### 6.3 Module 2.3: Cargo Loading (2 hours)

**Learning Objectives:**
- Properly load and secure cargo
- Verify cargo bay operation
- Set up winch delivery
- Conduct cargo checks

**Topics:**
1. Cargo mode loading procedure
2. Securing methods
3. Weight verification
4. Winch mode setup
5. Load cell verification
6. Pre-flight cargo checks
7. Common loading errors

**Practical Exercise:** Load and secure cargo (3 iterations)

### 6.4 Module 2.4: Flight Operations (4 hours simulation)

**Learning Objectives:**
- Operate FlyCart 30 in various conditions
- Execute cargo delivery procedures
- Respond to in-flight situations
- Manage emergencies

**Simulation Exercises:**
1. Basic flight familiarization
2. Cargo bay delivery
3. Winch delivery
4. Crosswind operations
5. Emergency procedures

### 6.5 Module 2.5: Practical Flight Training (8 hours)

**Learning Objectives:**
- Demonstrate safe FlyCart 30 operation
- Execute complete cargo delivery mission
- Handle emergencies appropriately

**Practical Exercises:**
1. Pre-flight inspection (2 iterations)
2. Cargo loading and verification
3. Takeoff and hover
4. Route navigation
5. Cargo bay delivery (3 iterations)
6. Winch delivery (3 iterations)
7. Return and landing
8. Emergency procedures
9. Complete mission (2 iterations)

**Competency Check:** Full mission assessment

## 7. Level 3: FlyCart 100 Qualification (Heavy RPAS)

### 7.1 Module 3.1: Heavy RPAS Regulations (3 hours)

**Learning Objectives:**
- Explain Heavy RPAS regulatory requirements
- Describe Transport Canada engagement process
- Understand enhanced documentation requirements
- Identify crew requirements

**Topics:**
1. Heavy RPAS definition (>150 kg)
2. Direct TC engagement requirements
3. Enhanced SFOC requirements
4. SORA compliance
5. Crew requirements (minimum 4)
6. Insurance requirements
7. Documentation requirements
8. Occurrence reporting (enhanced)

**Assessment:** Written exam (85% pass)

### 7.2 Module 3.2: FC100 Aircraft Systems (4 hours)

**Learning Objectives:**
- Describe FlyCart 100 systems in detail
- Explain redundant systems
- Understand safety systems operation
- Operate specialized systems

**Topics:**
1. Aircraft specifications (220 kg MTOW)
2. Octa-motor redundancy
3. Quad battery system
4. Triple-redundant flight controller
5. Dual parachute system
6. DAA system
7. ADS-B In/Out
8. Black box recorder
9. Structural monitoring
10. Cargo jettison system
11. Load cell array

**Assessment:** Systems competency test (90% pass)

### 7.3 Module 3.3: Emergency Systems (3 hours)

**Learning Objectives:**
- Operate parachute systems
- Execute cargo jettison procedures
- Respond to system failures
- Manage ground emergencies

**Topics:**
1. Dual parachute system operation
2. Parachute decision criteria
3. Cargo jettison system
4. Jettison decision criteria
5. Battery failure response
6. Motor failure response
7. Control system failures
8. Ground emergency response

**Practical Exercise:** Emergency procedures walkthrough

### 7.4 Module 3.4: Crew Resource Management (2 hours)

**Learning Objectives:**
- Coordinate multi-crew operations
- Apply CRM principles
- Communicate effectively
- Manage workload

**Topics:**
1. 4-person crew coordination
2. PIC responsibilities
3. Safety pilot role
4. Ground crew coordination
5. Communication protocols
6. Standard calls
7. Emergency coordination
8. Workload management
9. Decision making

**Practical Exercise:** Crew coordination scenarios

### 7.5 Module 3.5: Simulation Training (6 hours)

**Simulation Exercises:**
1. FC100 basic handling
2. Heavy cargo operations
3. Winch delivery operations
4. Wind and weather scenarios
5. Single/dual motor failures
6. Battery system failures
7. Parachute deployment scenarios
8. Cargo jettison scenarios
9. Lost link procedures
10. Complete mission scenarios

### 7.6 Module 3.6: Practical Flight Training (12 hours)

**Training Flights:**
1. Aircraft familiarization (unloaded)
2. Handling characteristics (loaded)
3. Pre-flight procedures (3 iterations)
4. Cargo loading and W&B verification
5. Standard delivery missions
6. Winch delivery missions
7. Multi-crew coordination
8. Abort and divert procedures
9. Emergency procedures (ground)
10. Full mission assessment (3 iterations)

**Competency Check:** Heavy RPAS competency assessment
