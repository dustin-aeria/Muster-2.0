# RPAS OPERATIONS SEQUENCE

## PHASE 1: MOBILIZATION

### 1.1 Documentation Check
```
☐ Site Survey complete
☐ FHA/FLHA prepared
☐ Airspace reviewed
☐ Permits confirmed
☐ Emergency contacts listed
```

### 1.2 Kit Preparation
```
☐ RPAS and backups
☐ Batteries CHARGED
☐ SD cards formatted
☐ Controller charged
☐ Software updated
☐ Documentation packed
☐ PPE (vest, glasses, gloves)
☐ Emergency kit (first aid, fire ext.)
☐ Radios charged
```

### 1.3 Team Briefing
```
☐ Objectives reviewed
☐ Roles assigned (PIC, VO)
☐ Safety protocols reviewed
☐ Communication protocols
☐ Weather conditions
☐ Airspace restrictions
☐ Questions addressed
```

---

## PHASE 2: SITE SETUP

### 2.1 Arrival Checks
```
☐ Walk site - identify hazards
☐ Verify site matches survey
☐ Update FLHA if needed
☐ Establish launch/recovery area
☐ Set up safety perimeter
☐ Position emergency equipment
☐ Test radios
☐ Check wind (within limits?)
☐ Final airspace check (NOTAMs)
```

---

## PHASE 3: RPAS SETUP

### 3.1 Aircraft Preparation
```
☐ Unpack carefully
☐ Visual inspection (frame, arms, motors)
☐ Propellers (secure, no damage)
☐ Payload installed and secured
☐ Battery inspected (no swelling)
☐ Battery installed and locked
☐ SD card installed
☐ Ground control powered and connected
☐ AirData synced
☐ Calibration if needed
```

### 3.2 Operations Ready
```
☐ All crew present and briefed
☐ Communication systems working
☐ Equipment in place
☐ Emergency gear accessible
☐ Weather within limits
☐ Airspace clear/authorized
☐ Site secure
```

---

## PHASE 4: POWER-UP

### 4.1 Power-Up Sequence
```
1. "Ground control on"
2. Power up RPAS → "RPAS ON" (loud)
3. Wait for initialization
4. "GPS locked, [X] satellites"
5. "Home point set"
6. "Failsafe [RTH/Land], [altitude]"
7. "Gimbal responding"
8. "Controls responsive"
9. "Telemetry good"
```

---

## PHASE 5: TAKE-OFF CHECKLIST

### 5.1 Call & Response (VO → PIC)
```
VO: "Wind & weather"     → PIC: "Within limits"
VO: "Air vehicle batteries" → PIC: "[X]%"
VO: "Ground control batteries" → PIC: "[X]%"
VO: "Ground control app" → PIC: "[App], connected, [X] sats"
VO: "Payload"            → PIC: "[Camera] secure"
VO: "Failsafe"           → PIC: "RTH at [X]%, [X]m altitude"
VO: "Take-off mode"      → PIC: "P-GPS"
VO: "Area & air traffic" → PIC: "Clear" or note issues
VO: "Cleared for takeoff" → PIC: "CLEAR!"
```

⚠️ **STOP if any response not acceptable**

---

## PHASE 6: FLIGHT OPERATIONS

### 6.1 Take-Off
```
1. Confirm area clear
2. Arm aircraft
3. Gentle throttle, lift off
4. Hover at 3-5m
5. Verify stable hover
6. Test attitude controls
7. Listen for abnormal sounds
8. Check telemetry
9. If anomaly → LAND
10. "Proceeding with operation"
```

### 6.2 During Flight
```
CONTINUOUS:
• Monitor flight path and telemetry
• Monitor battery
• Maintain crew communication
• Scan for aircraft (VO primary)
• Execute mission

PIC PRIMARY DUTY: Safe operation of RPAS
```

### 6.3 Battery Management
```
100-50%  → Normal operations
50-30%   → Begin returning
30-20%   → RTH if not already
Below 20% → Emergency priority - LAND
```

---

## PHASE 7: LANDING

### 7.1 Pre-Landing
```
☐ Landing area clear
☐ Battery sufficient
☐ Wind checked
☐ Announce "Returning" or "Landing"
```

### 7.2 Landing Sequence
```
1. Position over landing area
2. "Landing initiated"
3. Controlled descent
4. Touch down gently
5. Disarm
6. "RPAS safe for approach"
```

### 7.3 Battery Swap (if continuing)
```
1. VO approaches
2. VO swaps battery
3. VO inspects RPAS
4. VO: "Ready for pre-flight"
5. Complete Take-Off Checklist again
```

---

## PHASE 8: DEMOBILIZATION

### 8.1 Post-Flight
```
☐ Power down RPAS → "RPAS off"
☐ Power down GCS → "Ground control off"
☐ Remove battery
☐ Post-flight inspection
```

### 8.2 Pack Up
```
☐ Disassemble RPAS
☐ Store batteries (LiPo bag)
☐ Clean payload
☐ Secure all components
☐ INVENTORY CHECK - all items
☐ Clear site
```

### 8.3 Team Debrief
```

☐ Issues encountered?
☐ Safety observations?
☐ Equipment issues?
☐ Procedure improvements?
☐ Action items documented
```

### 8.4 Data Debrief (Back at base)
```
☐ Download data
☐ Backup data
☐ Review flight logs
☐ AirData upload
☐ Document findings
```

### 8.5 Equipment Management
```
☐ Charge batteries
☐ Clean equipment
☐ Log any issues
☐ Update AirData
☐ Schedule maintenance if due
☐ Store properly
```
