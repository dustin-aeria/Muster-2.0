## DELIVERY MODES

### CARGO MODE (Landing)

1. Confirm zone clear
2. Controlled descent
3. Land smoothly
4. Confirm on ground
5. Ground crew unload
6. Confirm cargo removed
7. Takeoff when clear

### WINCH MODE (Lowered)

1. Confirm zone clear
2. Hover at altitude
3. Deploy winch
4. Lower controlled
5. Confirm on ground
6. Release hook
7. Retract winch
8. Confirm stowed
9. Depart

## EMERGENCY PROCEDURES

### BATTERY FAILURE

1. Check remaining batteries
2. If 3+ batteries OK - proceed to landing
3. If <3 batteries - IMMEDIATE landing
4. Activate parachute if unable to control

### CARGO SHIFT

1. Reduce speed immediately
2. Assess controllability
3. Proceed to NEAREST safe landing
4. DO NOT continue mission
5. Land and inspect

### LOSS OF CONTROL

1. **RELEASE CONTROLS momentarily**
2. Assess if aircraft stabilizes
3. If stable - regain gentle control
4. If unstable - **DEPLOY PARACHUTE**
5. Clear area below

### PARACHUTE DEPLOYMENT

**Deploy parachute when:**
- Loss of control unrecoverable
- Multiple motor failures
- Structural failure indication
- Fire/smoke

**Deployment procedure:**
1. Arm parachute (if not auto)
2. Confirm deploy command
3. Both parachutes deploy
4. Clear area below
5. Note landing location
6. Coordinate recovery

### CARGO JETTISON

**Jettison ONLY when:**
- Aircraft control compromised AND
- Cannot reach safe landing AND
- Jettison zone is clear

**NEVER jettison over:**
- People
- Vehicles/roads
- Populated areas
- Without clearance confirmation

**Jettison procedure:**
1. Confirm decision necessary
2. Identify clear zone below
3. Two-stage activation:
   - Stage 1: Arm
   - Stage 2: Release
4. Confirm cargo released
5. Document location

### LOST LINK

1. Automatic RTH activates
2. Monitor if possible
3. Prepare for landing at home
4. Ground crew standby
5. If no recovery - expect parachute
