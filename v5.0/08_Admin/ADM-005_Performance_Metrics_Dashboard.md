## 1. Purpose

This document establishes the key performance indicators (KPIs) and metrics used to measure safety, operational, and business performance. It provides a standardized dashboard for monitoring organizational health and driving continuous improvement.

---

## 2. Scope

This dashboard applies to:
- Safety management system performance
- Operational efficiency and effectiveness
- Regulatory compliance
- Client satisfaction
- Business performance

## 10. Target Setting and Review

### 10.1 Annual Target Review

- Review all targets during annual management review
- Adjust based on prior year performance
- Consider industry benchmarks
- Set challenging but achievable goals

### 10.2 Threshold Adjustments

- Thresholds define minimum acceptable performance
- Below threshold requires immediate investigation
- Thresholds may be tightened as performance improves
- Safety thresholds are non-negotiable

---

## 11. Response to Metrics

### 11.1 Green Status (On Target)

- Continue current practices
- Look for improvement opportunities
- Document best practices

### 11.2 Yellow Status (Below Target)

- Investigate root cause
- Implement corrective actions
- Monitor closely
- Report to Operations Manager

### 11.3 Red Status (Below Threshold)

- Immediate investigation required
- Implement immediate corrective actions
- Report to Accountable Executive
- Document in corrective action system
- May require operations adjustment
